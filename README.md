# AWS Static Website Hosting

## Project Overview

This project demonstrates how to host a static website on AWS using Amazon S3 and Amazon CloudFront.

The project includes configuring website hosting, CloudFront distribution, custom domain, and secure HTTPS access.

## AWS Services Used

- Amazon S3
- Amazon CloudFront
- Amazon Route 53
- AWS Certificate Manager (ACM)

## What I Did

- Created an Amazon S3 bucket
- Uploaded static website files to S3
- Configured the S3 bucket for website hosting
- Configured Amazon CloudFront
- Connected CloudFront with the S3 origin
- Configured a custom domain
- Configured HTTPS using SSL/TLS
- Tested website access through the domain
